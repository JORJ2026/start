Put this on your home screen

Opens like an app, with your name already picked.

  1. Open this page in Safari (not inside another app).
  2. Tap the Share button (square with an arrow) at the bottom.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add. The icon appears on your home screen.

Apple doesn’t allow a button to do this for you, so these steps are the only way on iPhone.

  1. Open this page in Chrome.
  2. Tap the ⋮ menu in the top right.
  3. Tap Install app or Add to Home screen.
  4. Tap Install to confirm.

If the Install button above doesn’t appear, use the menu steps.
