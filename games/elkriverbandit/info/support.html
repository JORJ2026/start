Help & FAQ

📱 Install on iPhone / iPad

Open the game in Safari, tap the Share button, then Add to Home Screen. It then opens full-screen and works offline. (An unsigned .ipa is also published for sideloading tools such as AltStore or Sideloadly; the App Store needs a paid Apple developer account.)

🤖 Install on Android

Easiest: open the game in Chrome and tap Install app in ⚙️ Settings → Download. Or download the .apk from Settings → Download and open it — allow “install unknown apps” for your browser if asked.

🪟 Windows says “protected your PC”

The installer isn’t code-signed. Click More info → Run anyway.

🍎 macOS says the app is damaged or from an unidentified developer

Open the .dmg, drag the app to Applications, then right-click → Open the first time. If it still refuses, run xattr -cr "/Applications/Elk River Bandit.app" in Terminal.

🐧 Linux

AppImage: chmod +x Elk-River-Bandit-*.AppImage then double-click or run it. Debian/Ubuntu: sudo apt install ./Elk-River-Bandit-*.deb.

🔊 No sound

Check ⚙️ Settings → Sound, your volume and the silent switch. Tap the screen once — browsers wait for a tap before playing audio.

💾 Move my progress to another device

⚙️ Settings → More → Save backup, then Restore backup on the other device.

🐞 Report a problem

⚙️ Settings → More → Report a problem opens a pre-filled GitHub issue with diagnostics.
