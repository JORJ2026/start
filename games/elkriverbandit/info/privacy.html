Privacy

Last updated: November 2026

The short version

Elk River Bandit has no accounts, no ads, no analytics and no tracking. We collect nothing about you.

What is saved

High scores, level progress, stats, achievements and settings are stored only on your device (browser local storage, or the app’s local storage). They are never uploaded. You can save, restore or erase them in ⚙️ Settings → More.

Network use

WhenWhat
Opening ⚙️ Settings → Download, or “Check for updates”The game asks GitHub’s public API for the latest release number. GitHub may see your IP address, like any website you visit.
Playing the web versionFiles load from the website’s host (GitHub Pages). After the first load the game works offline.

The game does not use cookies, advertising IDs, location, camera or microphone.

Children

Safe for children: no chat, no sign-in, no purchases, no outside links inside the game itself.

Contact

Open an issue on the project’s GitHub page — see Help.
