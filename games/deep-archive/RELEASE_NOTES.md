# Release notes — 1.1.0

- Re-art-directed the title, loading, settings, and pause screens around new underwater archive key art, a restrained teal/gold palette, and a clearer hierarchy.
- Added an asset-aware loading screen and full settings panel: independent music/SFX level, master mute, fullscreen, and input reference.
- Added standard Gamepad API support: analog stick/D-pad movement, A/Cross confirm, B/Circle back, X/Square or right bumper pulse, and Start/Menu pause; menus support gamepad focus navigation.
- Improved touchscreen support and multi-direction touch input; controls appear when the browser reports touch/coarse input.
- Replaced the previous single ambient bed with an original loopable score and four authored procedural sound effects, each with independent SFX/music gain controls.
- Added a custom diver sprite rendered from Canvas geometry and more detailed archive tile surfaces.
- Known limitation: no physical controller or touch device was attached to the headless QA browser, so those devices were not hardware-tested. The gamepad code follows the standard browser mapping.
