# Release notes — Field Edition

- First complete playable campaign content: ten authored regions and twenty authored investigations.
- Added tag-based investigation, evidence inspection costs, supported/contested theories, communal testimony and durable colony consequences.
- Added expanding frontier, survey, route logistics, resource upkeep/recovery, five autonomous settlement behaviors, ecological/population/trust state, inherited trait discovery and cultivation, hybrid lineage, research branches and 30 milestones.
- Added title screen, three difficulty profiles, integrated first-session prompt, pause, settings, local auto-save, JSON export, chronicle, two campaign resolutions and credits.
- Original generated Art Nouveau frontier artwork and a locally synthesized seamless ambience loop; Web Audio interface/discovery tones and separate music/effects settings.
- Known limitation: no in-game save import UI, server synchronization, native executable, or complete playthrough QA. The environment could not run a full human campaign test during the build.
